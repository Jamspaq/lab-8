Зертханалық-тәжірибелік жұмыс № …
Тақырыбы:

GitHub Issues және Projects (Kanban) арқылы жобаны басқару. GitHub Actions көмегімен автоматтандыру негіздері

Мақсаты:

Білім алушыларды GitHub-та жобаларды басқарудың заманауи құралдарымен таныстыру:

Issues арқылы тапсырмаларды тіркеу және бақылау;

Projects (Kanban) тақтасы арқылы жұмысты жоспарлау;

GitHub Actions көмегімен автоматтандырылған тексерулерді іске қосу.

Командалық жобада жұмыс үдерісін ұйымдастыру және автоматтандыру дағдыларын қалыптастыру.

Қажетті құралдар:

GitHub аккаунты

Алдыңғы зертханалық жұмыстарда құрылған репозиторий

Интернет браузер

Git (қажет болған жағдайда)

Жұмыс барысы (қадам-қадам бойынша)
1-қадам. GitHub Issues құру

Негізгі репозиторийге өтіңіз.

Issues қойындысын ашыңыз.

New issue батырмасын басыңыз.

Мысалы, келесі тақырыпта issue құрыңыз:

Title: Басты бетке қатысушылар тізімін қосу

Description:

Не істеу керек

Қандай файлдар өзгереді

Қабылдау критерийі

Issue-ды сақтаңыз.

📌 Ескерту: Әр қатысушы кемінде 1 Issue құруы тиіс.

2-қадам. Issue-ды орындаушыға тағайындау

Issue бетінде:

Assignees бөлімінен орындаушыны таңдаңыз;

Labels арқылы белгілер қосыңыз (bug, enhancement, documentation).

Issue-ға мерзім мен түсіндірме жазыңыз.

3-қадам. GitHub Projects (Kanban) тақтасын құру

Репозиторийден Projects → New project таңдаңыз.

Board (Kanban) түрін таңдаңыз.

Бағандарды жасаңыз:

To Do

In Progress

Review

Done

Құрылған Issues-ті тиісті бағандарға сүйреп орналастырыңыз.

4-қадам. Issue негізінде тармақ (branch) құру

Issue бетінде Create a branch for this issue батырмасын басыңыз.

GitHub автоматты түрде жаңа тармақ жасайды.

Локалды репозиторийде тармақты жүктеңіз:

git fetch
git checkout <issue-branch-name>

5-қадам. Тапсырманы орындау және Pull Request жасау

Issue талаптарына сай өзгерістер енгізіңіз.

Өзгерістерді сақтаңыз:

git add .
git commit -m "Issue #X орындалды"
git push origin <branch-name>


Pull Request жасаңыз.

Pull Request сипаттамасында:

Closes #X


деп көрсетіңіз.

6-қадам. GitHub Actions арқылы автоматтандыру
6.1 GitHub Actions файлын құру

Репозиторийде келесі құрылымды жасаңыз:

.github/workflows/html-check.yml


Файлға келесі мазмұнды жазыңыз:

name: HTML Check

on: [push, pull_request]

jobs:
  validate-html:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: HTML validation
        run: echo "HTML файлдары тексерілді"

6-қадам. Workflow тексеру

GitHub-та Actions қойындысына өтіңіз.

Pull Request ашқанда немесе push жасағанда workflow іске қосылғанын тексеріңіз.

Жасыл белгі – тапсырма сәтті орындалды.

Командаларға нұсқаулық (қысқаша)
Команда	Мақсаты
git fetch	Қашықтағы өзгерістерді алу
git checkout <branch>	Тармаққа ауысу
git commit -m	Өзгерістерді сақтау
git push	Өзгерістерді GitHub-қа жіберу
Closes #X	Issue-ды автоматты жабу
Тапсырма:

Репозиторийде кемінде 3 Issue құрыңыз.

Projects (Kanban) тақтасында тапсырмаларды орналастырыңыз.

Бір Issue-ды branch → commit → Pull Request арқылы орындаңыз.

GitHub Actions workflow-ты іске қосыңыз.

Pull Request сәтті біріктірілуі тиіс.

Нәтиже:

Зертханалық жұмыс соңында білім алушылар:

GitHub Issues арқылы тапсырмаларды басқаруды;

Kanban тақтасымен жұмыс істеуді;

GitHub Actions көмегімен автоматтандыруды;

Нақты DevOps және командалық әзірлеу тәжірибесін меңгереді.
